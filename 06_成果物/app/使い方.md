# NISAシグナル 試作品 v0.4(段階2)の使い方

- スマホで見る: https://claude.ai/artifact/HF8Y6ruHoCcYLsB5kgXPAk (Claudeにログインして開く。小林さん専用・非公開)
- 段階5からは GitHub Pages で公開し、ホーム画面に追加して使う

## 画面
| 画面 | できること |
|---|---|
| 上のボタン | 投資スタイル(短期・中期・長期)の切り替え |
| ホーム | マーケット(日経平均・S&P500・SOX指数・ドル円)、おすすめランキング、売りの検討ランキング、損切り・利確のお知らせ、NISA枠の残り、今月の売買回数 |
| 銘柄 | おすすめ度順の一覧、自動取得した株価、相性の内訳(観点ごとの点数) |
| 検討 | 検討リスト。自動チェックと自分での確認を済ませて、買う・売る・見送るを決める |
| 売買記録 | 売買の記録。NISA枠の上限・つみたて枠のルールを自動で確認 |
| 設定 | 資金、枠の計画、売買回数の上限、購入額の目安、損切り・利確ライン |

## データ
| データ | 状態 |
|---|---|
| 株価・ドル円・指数 | **実データ**(yfinance)。毎朝7時30分に自動取得(GitHub設定後) |
| 値動き・騰落率・出来高・200日線・RSI | **実データ**(株価から計算) |
| PER・PBR・ROE・配当・自己資本比率・増益率・決算日 | **実データ**(yfinance)。取れないものは採点から外す |
| 投資信託の基準価額・純資産 | **実データ**(三菱UFJアセットマネジメントのCSV) |
| 判定の点数(数値・AI)・ニュースの話題度・市況まとめ | サンプル → 段階3・4で置き換え |

## ファイル
| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体 |
| `data/market.json` | 自動取得したデータ(毎朝上書き) |
| `scripts/fetch_data.py` | データを取得するプログラム |
| `scripts/watchlist.json` | 自動取得する銘柄の一覧。アプリで銘柄を追加したら、ここにも追加する |
| `.github/workflows/fetch-data.yml` | 毎朝の自動実行の設定 |

手元で取得を試すとき(06_成果物フォルダで):
```
.venv\Scripts\python.exe app\scripts\fetch_data.py
```

## 保存
入力内容(保有・売買記録・検討メモ・設定)はスマホのブラウザの中だけに保存する。外部には送らない。
